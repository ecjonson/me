# Security Policy

## Scope

Only the live site and the `main` branch are supported. Older commits and
forks are out of scope.

## Reporting a vulnerability

Please don't open a public issue for security problems.

[Report a vulnerability privately](https://github.com/PixelsRN/pixelsrn.com/security/advisories/new) through GitHub instead: go to the **Security** tab of this
repo and click **Report a vulnerability**. Only I can see the report. Include what you found, the page or endpoint involved, and steps to reproduce
it if you can.

## What to expect

This is a personal site maintained by one person. I'll acknowledge your report
within a week and keep you posted while I work on a fix. Once it's resolved,
I'm happy to credit you in the advisory if you'd like.
